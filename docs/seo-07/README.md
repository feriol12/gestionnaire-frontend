2. Dans `C:\PROJETS\GestionDepense\gestionnaire-frontend`, créer `docs\seo-07` si nécessaire.
3. Copier les 4 fichiers ci-dessus dans `docs\seo-07`.
4. Ouvrir `SEO-07_PROMPT_IMPLEMENTER.md`, copier le contenu vers l'agent Implementer (Claude Code, Codex ou autre) dont le dossier de travail est ce repo.
5. L'agent doit vérifier l'état de Git et les instructions de dépôt avant toute modification.
6. Si les fichiers sont ajoutés au dépôt, ils doivent rester uniquement des ressources de conception ; l'agent doit contrôler le diff et la branche avant de les committer.

Trello : créer manuellement la carte avec le titre et la description de `SEO-07_CARTE_TRELLO.md` si l'intégration automatique n'est pas accessible. Joindre les deux captures ou le ZIP si possible.
